✨ Зажмите и потяните грань кубика для вращения.
💡 Подсказка: Попробуйте собрать белый крест на верхней грани!

📋 Памятка для новичка

1. Анатомия кубика: Куб состоит из элементов 3 типов:

  • Центры (6 шт): Неподвижны друг относительно друга, задают итоговый цвет грани.
  • Рёбра (12 шт): Элементы с 2 цветами.
  • Углы (8 шт): Элементы с 3 цветами.

2. Управление: Потяните за цветную наклейку, чтобы повернуть слой. Потяните за пустой темный фон вокруг, чтобы вращать камеру.

3. Проверенная стратегия сборки:

  • Шаг 1: Соберите правильный белый крест на верхней грани (боковые ребра должны совпадать по цвету с боковыми центрами).
  • Шаг 2: Поставьте на места 4 белых угла (нижний слой готов).
  • Шаг 3: Собрать средний слой, расставив боковые ребра.
  • Шаг 4: Желтый крест наверху и выравнивание его ребер.
  • Шаг 5: Расстановка и разворот желтых углов.
